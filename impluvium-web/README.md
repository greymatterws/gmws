# Impluvium — front page (preview)

Static page for tax.greymatterws.com: Impluvium lockup, a dummy chat box, and disclaimers.
The chat is not connected to anything. Sending a message shows a "not connected" reply.

## Files
- `index.html` - the page (styles and script inline)
- `assets/impluvium-mark.svg` - halftone square mark, navy
- `assets/halftone-diamond.svg` - GMWS background diamond, navy (same geometry as the client portal's)
- `assets/favicon-32.png`, `assets/apple-touch-icon.png` - browser/phone icons

## Palette
- Ground #D7D6D3 (logo background), lift #E1E0DD, deep #CBCAC6
- Chat card #E4E3E0, input #ECEBE8
- Ink #0F161F (logo navy), steel #5B6573, small text #565B62
- Type: Instrument Serif (display, buttons), system sans (chat text, footer)

## Notes
- Background diamond is the client portal's, inked navy at 8.5% opacity.
- Footer uses Impluvium™ (unregistered mark). Switch to ® only after USPTO registration.
